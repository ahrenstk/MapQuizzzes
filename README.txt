Information (en):

- Home page and instructions are configured in MapQuizzzes.json
- Imprint and Privacy are configured in imprint.html and privacy.html
- background image is images/background.jpg and can be customized
- a quiz can contain multiple tours
- either direct single answers or multiple choice answers with up to three incorrect entries can be used.
- the Bourtange quiz has only one tour in two versions, "Bourtange Fortress (Step-by-Step)" and "Bourtange Fortress (Complete Map)"
- the "Festung Bourtange" folder contains all documents for the "Festung Bourtange" tour
- use large images with a width of 500px if possible (folder img)
- use thumbnail images with a width of 100px if possible (folder min)
- a placeholder is used for missing images
- Modal headers, modal footers, and extra modals are available as optional HTML text files (e.g., in modalheader/, modalfooter/, or modalextra/, each saved as bild.jpg.txt).
- quizdata.json contains the quiz data
- "stepbystep": true for Step-by-Step mode and "stepbystep": false for Complete Map mode
- use gpx file named quizdata.gpx (create GPX files, e.g., using https://brouter.de/brouter-web or https://gpx.studio/de)
- set 'gpxShow' from 0 to 1 to define the length for a growing GPX line.
- questions, hints, and answers are optional
- gallery.php for displaying galleries
- upload.php for uploading and converting JPG images (folders img and min)
- img/index.php and min/index.php for read restrictions (optional)
- website can be installed by the user - Progressive Web App (PWA)

Informationen (de):

- die Startseite und die Anleitungen werden in MapQuizzzes.json konfiguriert.
- Impressum und Datenschutz werden in imprint.html und privacy.html konfiguriert.
- das Hintergrundbild ist images/background.jpg und kann individuell angepasst werden.
- ein Quiz kann mehrere Touren enthalten.
- es können sowohl direkte Einzelfragen als auch Multiple-Choice-Antworten mit bis zu drei falschen Optionen verwendet werden.
- das Bourtange-Quiz hat nur eine Tour in zwei Varianten, „Festung Bourtange (Step-by-Step)“ und "Festung Bourtange (Complete Map)"
- der Ordner „Festung Bourtange“ enthält alle Dokumente für die „Festung Bourtange“-Tour.
- verwende nach Möglichkeit große Bilder mit einer Breite von 500px (Ordner img).
- verwende nach Möglichkeit Vorschaubilder (Thumbnails) mit einer Breite von 100px (Ordner min).
- für fehlende Bilder wird ein Platzhalter verwendet.
- Modal-Header, Modal-Footer und Extra-Modals sind als optionale HTML-Texte verfügbar (z. B. in modalheader/, modalfooter/ oder modalextra/ jeweils als bild.jpg.txt).
- quizdata.json enthält die Quizdaten.
- "stepbystep": true für den Schritt-für-Schritt-Modus und "stepbystep": false für den Modus „Vollständige Karte“.
- verwende eine GPX-Datei mit dem Namen quizdata.gpx (GPX-Dateien lassen sich z. B. mit https://brouter.de/brouter-web oder https://gpx.studio/de erstellen).
- setze gpxShow von 0 auf 1, um die Länge für eine wachsende GPX-Linie zu definieren.
- Fragen, Hinweise und Antworten sind optional.
- gallery.php dient zur Anzeige von Galerien.
- upload.php dient zum Hochladen und Konvertieren von JPG-Bildern (Ordner img und min).
- img/index.php und min/index.php dienen zur Lesebeschränkung (optional)
- Website kann vom Benutzer installiert werden - Progressive Web App (PWA)
